Teach Mode

Kinesthetic teaching — physically guide the robot, capture motion + gripper steps, save as a sequence.

Overview

Teach Mode puts the robot into a compliant state — Joint Admittance (Mode 3) or Cartesian Admittance (Mode 7) depending on the active Mode selector — so you can physically guide it by hand. Motion waypoints (joint or cartesian) and gripper waypoints are captured into a single timeline and can be saved as a sequence for automated playback.

Teach Mode is an extension (Extensions/teach_mode/) and appears in the sidebar under Programming. Saving into the sequence library requires the Sequences extension to be enabled as well.

How Hand-Guiding Works

Teach Mode is not a zero-torque / gravity-float mode. The admittance controller keeps the inner impedance loop stiff and instead moves the reference under your push (“push-and-stay”): the external torque estimate (model gravity torque minus measured torque) is fed through a deadband into an admittance block that accumulates a persistent offset on the target. Release the arm and it holds position where you left it; the offset is anti-windup-clamped at joint limits so pushing against a hard stop does not wind up.

DeadbandDefaultApplies To
joint_tau1.5 NmJoint Admittance (Mode 3) — per-joint external torque
cart_force4.0 NCartesian Admittance (Mode 7) — EE translational force
cart_torque0.2 NmCartesian Admittance (Mode 7) — EE rotational torque

Deadbands are per-robot, loaded from the admittance_deadbands block in fic_library/config/robots_config.yaml (see Robot Config). Too low a deadband makes the arm drift on gravity-model error; too high makes it feel sticky. On the Franka, an unregistered tool adds 1–2 Nm of bias to the external-torque estimate in heavy poses — register payloads before lowering joint_tau.

Workflow

  1. Ensure the FIC controller is running (simulation or hardware).
  2. Open the Teach Mode panel.
  3. Pick the Target Robot in the title row (multi-robot sessions only) and the active control space in the Mode selector:
    • Joint — teach in joint space; Start Teaching activates Joint Admittance.
    • Cartesian — teach in EE pose space; Start Teaching activates Cartesian Admittance.
  4. Click Start Teaching and confirm the dialog — the robot switches to the matching admittance mode automatically. The Mode selector locks while the session is live so the recorded data and the active mode can't desync.
  5. Physically guide the robot to the desired positions.
  6. Capture motion waypoints with the Record Current Position button (manual) or enable Auto-record.
  7. Use the Gripper group at any point to actuate the gripper (OPEN / CLOSE / APPLY) and click Record Gripper Waypoint to drop a gripper-only step into the timeline at that moment.
  8. Click Stop Teaching — the robot switches to the matching planner (Joint Impedance With Planner for Joint, Cartesian Impedance with Planner for Cartesian).
  9. Review the recorded waypoints in the table on the right.
  10. Click Save as Sequence to store them; they appear in the Sequences panel.

If you click Start Teaching while the controller is down, the panel arms anyway but logs “No mode publisher on the GUI node — robot mode not switched” to the Logs. Start the controller first, then re-arm.

Gripper Controls

The Gripper group lets you actuate the end-effector while teaching, so you can manipulate parts and feel the closure moment before deciding to capture.

ControlEffect
Width spinboxSets the displayed target width (0.0–0.08 m, 0.005 m steps, default 0.08 m). Live percent readout next to it.
OPENSets width to 0.08 m and publishes immediately.
CLOSESets width to 0.0 m and publishes immediately.
APPLYPublishes whatever the spinbox currently shows. Use for arbitrary widths (e.g. 0.04 m to grasp a 40 mm part).
Record Gripper WaypointAdds a type:'gripper' step at the current spinbox width to the recorded timeline. Disabled when no teach session is active.

All actuator buttons publish through node.publish_gripper_width(rid, width) — the same path the Sequences and Control panels use — so what you feel during teaching is what the saved sequence will reproduce.

Live Display

While teaching, the panel polls the robot state every 50 ms (20 Hz) showing:

  • Joint positions — one readout per joint (hidden rows collapse to the robot's joint count)
  • Cartesian pose — X, Y, Z (mm) + Roll, Pitch, Yaw (degrees, converted from the EE quaternion)

Feedback comes from the shared joint-state subscribers: {rid}_q_current (Float64MultiArray) and {rid}_ee_current_pose (Pose), with joint_states / simulation_joint_states as unprefixed fallbacks (see Topics).

Both joint and cartesian feedback are stored on every recorded motion waypoint, regardless of which Mode the session is in — the 'mode' tag just decides which one is the playback target.

Editing Waypoints

  • Go — after a confirmation dialog, sends the right command for the waypoint's mode: joint angles for Joint waypoints, EE pose for Cartesian, gripper width for Gripper.
  • Undo Last — remove the most recently recorded waypoint
  • Clear All — remove all recorded waypoints (asks for confirmation)
  • Delete (✕ on the row) — remove a specific waypoint

Multi-robot sessions

The live display and recorded waypoints always read from the first active robot's feedback (host.current_joint_positions / current_ee_pose), while commands go to the selected Target Robot. In a multi-robot session, keep the target on the first robot when teaching — otherwise you would hand-guide one arm while recording another's state.

Safety

In teach mode, the robot is compliant and will move freely. Keep a firm grip, especially near joint limits. The safety system still monitors limits and will warn on violations. Keep E-STOP accessible at all times when teaching on real hardware — an emergency stop automatically ends the teach session (already-recorded waypoints are kept). The session is also ended cleanly if the extension is torn down (e.g. on application exit).

Switching modes mid-session

The Mode selector locks while a teach session is live. To switch between Joint and Cartesian, click Stop Teaching, change the selector, then Start Teaching again. The waypoints already in the table are preserved — you can mix Joint, Cartesian, and Gripper waypoints across multiple sessions and save them as a single sequence.

Troubleshooting

SymptomCause / Fix
Robot mode doesn't change on Start TeachingThe controller isn't running — the log shows "No mode publisher on the GUI node". Start fic_simulation / fic_hardware (see Processes), then Stop and Start Teaching again.
Arm feels sticky / needs a hard shoveAdmittance deadband too high for this robot or payload. Lower admittance_deadbands.joint_tau (or cart_force) in fic_library/config/robots_config.yaml and restart the controller.
Arm drifts on its own in teach modeGravity-model error exceeds the deadband — typically an unregistered tool/payload. Register the payload or raise the deadband.
