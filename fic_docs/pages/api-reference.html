Script API Reference

All functions available in the Script Editor plus the standalone fic_api package.

There are two Python APIs. The Script Editor extension (this page, first half) runs scripts inside the studio process with a robot facade object and flat alias functions that map to every GUI action the studio can perform. The standalone fic_api package (second half) provides a Robot class you can use from any Python script, Jupyter notebook, or IDE — no studio GUI required.

Open the Script Editor page from the sidebar (Programming › Script Editor; Ctrl+6 in the Classic interface). Open an example or one of your scripts, edit it, and press ▶ Run (Ctrl+Enter); ■ Stop ends it. On the web page a run goes to the Studio's own target (Simulation / Hardware / VR in the top bar, shown as Runs on above the editor) and asks first on Hardware; the Classic page has its own Target dropdown. Any browser that holds control in the web interface can save and run scripts.

Editor Layout

In the web interface (and the Docker image) the page has two toolbar rows above a full-width editor: the script picker with New / Save / Save as… / Delete and Runs on; then Run / Stop, the run's status, and the Examples and API drawers. The output is under the editor. The API drawer is this page's first half, searchable; choosing an entry inserts it at the cursor. The Classic interface keeps its three panes (editor and examples tabs, telemetry and API reference, output console) and its Target Robot combo. See Script Editor for both.

The robot Object

Every script receives a robot variable (a RobotAPI instance) plus flat aliases for the most common calls:

Properties (Signature: property) are read without brackets: robot.state.joints, not robot.state.joints().

# Grouped namespace
joints = robot.state.joints          # list[float], degrees
robot.motion.move_joints([0, -45, 0, -90, 0, 45, 0], wait=True)
robot.mode.set(2)                    # Joint Impedance With Planner

# Flat aliases (backward-compatible)
joints = get_joint_positions()
move_joints([0, -45, 0, -90, 0, 45, 0], wait=True)
set_mode(2)

Thread-Safety Model

OperationThread
node.publish_* (motion, mode, tune, topics)Worker thread — direct call
JointStateMixin reads (robot.state.*)Worker thread — direct call
GUI / subprocess ops (process.*, target.*, tuning save)Main thread via marshal()

Calling marshal() on a publish method would deadlock — never do that.

Cooperative Stop

Scripts can be stopped cleanly by pressing ■ Stop in the toolbar. The is_stopped() predicate returns True once a stop is requested; wait() and move_joints(wait=True) poll it at ~20 Hz and return early. After a 2-second grace period the runner calls terminate() as a last resort.

for wp in WAYPOINTS:
    if is_stopped():
        break
    robot.motion.move_joints(wp, wait=True, timeout=10.0)
    robot.wait(0.5)

robot.motion — Joint-Space and Cartesian Motion

Publishes directly from the worker thread (thread-safe).

MethodSignatureUnitsDescription
robot.motion.move_joints (angles_deg, wait=False, timeout=10.0, tolerance=None) degrees Publish joint angles; optionally block until reached. tolerance=None means the 2.0° per-joint default. Returns None (no-wait), True (reached), or False (timeout / stop).
robot.motion.move_cartesian (x, y, z, rx=0.0, ry=0.0, rz=0.0) m / rad Publish a Cartesian pose command.
robot.motion.home () — Move to the home position from the robot config (q_home_deg; falls back to the Franka home [0, -45, 0, -90, 0, 45, 0]). Non-blocking.
robot.motion.set_gripper (width_m) m Set gripper width clamped to [0, 0.08].
robot.motion.open_gripper () — Open gripper fully (0.08 m).
robot.motion.close_gripper () — Close gripper fully (0.0 m).
# Move to home position and wait up to 10 seconds
reached = robot.motion.move_joints(
    [0.0, -45.0, 0.0, -90.0, 0.0, 45.0, 0.0],
    wait=True,
    timeout=10.0,
    tolerance=1.5,
)
print('reached:', reached)

# Cartesian move (metres; rx/ry/rz in radians)
robot.motion.move_cartesian(0.4, 0.0, 0.3, rx=0.0, ry=0.0, rz=0.0)
Routing and units

Where the command goes depends on the target: Simulation and VR publish a JointState to {rid}_target_joint_angles; Hardware publishes a Float32MultiArray to {rid}_desired_joint_angles. move_cartesian publishes a Pose to command_ee_position_change_{rid} and only has an effect in a Cartesian mode (5–8). Orientation is Euler XYZ converted to a quaternion via SciPy; if SciPy is missing, identity orientation is sent. The legacy move_joints(angles, velocity=...) argument is deprecated — it is ignored and emits a DeprecationWarning.

robot.tune — Parameter Tuning

MethodSignatureDescription

On the wire, param_update publishes a String of the form robotN:<param_type>:<value> on robot{N}_param_update. See Tuning for the parameter types and Config XML for where tune.save writes.

# Ask the controller to re-read config.xml (after robot.tune.save)
robot.tune.param_update(0, 0)
robot.wait(0.2)

robot.safety — Emergency Stop

MethodDescription
robot.safety.estop()Publish mode 1 (park) and trigger GUI emergency stop.
robot.safety.broadcast_stop()Send stop to every active robot (marshalled).

wrench = robot.state.wrench
if wrench and abs(wrench[2]) > 20.0:   # Fz > 20 N
    robot.safety.estop()

robot.topics — Generic ROS Topics

MethodSignatureDescription
robot.topics.list_topics()Return [(name, type_str), ...] from the ROS graph.
robot.topics.subscribe(topic_name)Subscribe to a topic (auto-discovers type).
robot.topics.unsubscribe(topic_name)Destroy the subscription and clear cache.
robot.topics.get(topic_name)Return the latest message for the topic as a plain dict, or None.
robot.topics.cleanup()Destroy all subscriptions (called at teardown).

Messages are serialised to dicts, not returned as ROS objects. Known types (Float64MultiArray, Float32MultiArray, JointState, Pose, Wrench, WrenchStamped, scalar std_msgs) get structured keys; anything else falls back to {'type': ..., 'data'/'raw': ...}. A Pose arrives as {'type': 'Pose', 'position': {'x','y','z'}, 'orientation': {'x','y','z','w'}}.

topics = robot.topics.list_topics()
print(f'Found {len(topics)} topics')

robot.topics.subscribe('/robot1_ee_current_pose')
robot.wait(0.2)
msg = robot.topics.get('/robot1_ee_current_pose')   # dict or None
if msg:
    print(f"EE: {msg['position']['x']:.3f}")

Examples

These five scripts are seeded into ~/.fic_studio_scripts/examples/ the first time the extension loads (existing files are never overwritten) and appear in the Examples tab of the editor. The versions below are abridged; the seeded files carry extra prints and comments.

Example 01 — Read State

"""01_read_state.py — Read robot state using the new API."""
print('=== Read State Example ===')

joints = robot.state.joints          # list[float], degrees
print(f'Joint positions (deg): {[f"{j:.1f}" for j in joints]}')

ee = robot.state.ee_pose             # [x, y, z, qx, qy, qz, qw] or []
if ee:
    print(f'EE position (m): x={ee[0]:.3f}  y={ee[1]:.3f}  z={ee[2]:.3f}')

wrench = robot.state.wrench
if wrench:
    print(f'Wrench (N/Nm): Fx={wrench[0]:.2f}  Fy={wrench[1]:.2f}  Fz={wrench[2]:.2f}')

Example 02 — Joint Trajectory

"""02_joint_trajectory.py — Move through a simple joint-space trajectory."""
WAYPOINTS_DEG = [
    [0.0,  -45.0,  0.0, -90.0, 0.0,  45.0, 0.0],
    [30.0, -30.0, 20.0, -60.0, 0.0,  60.0, 0.0],
    [0.0,  -45.0,  0.0, -90.0, 0.0,  45.0, 0.0],
]

for idx, wp in enumerate(WAYPOINTS_DEG):
    if is_stopped():
        print('Stopped by user.')
        break
    print(f'Moving to waypoint {idx + 1}/{len(WAYPOINTS_DEG)}...')
    reached = robot.motion.move_joints(wp, wait=True, timeout=15.0, tolerance=1.5)
    print(f'  {"Reached" if reached else "Timeout/stopped"}')
    robot.wait(0.3)

Example 03 — Cartesian Circle

"""03_cartesian_circle.py — Sweep a small circle in Cartesian space."""
import math

RADIUS_M = 0.05
N_STEPS = 24
CENTRE = (0.4, 0.0, 0.3)

for i in range(N_STEPS + 1):
    if is_stopped():
        break
    angle = 2 * math.pi * i / N_STEPS
    x = CENTRE[0] + RADIUS_M * math.cos(angle)
    y = CENTRE[1] + RADIUS_M * math.sin(angle)
    robot.motion.move_cartesian(x, y, CENTRE[2])
    robot.wait(0.08)

Standalone fic_api Package

The fic_api/ directory at the repo root is a pip-installable package with a Robot class that talks to the same ROS topics as the studio — from plain Python, Jupyter, or any IDE. It creates a lightweight ROS 2 node spun by a SingleThreadedExecutor in a background daemon thread.

Install

# Source ROS 2 and the workspace first
source /opt/ros/$ROS_DISTRO/setup.bash        # humble / jazzy / kilted
source ~/FIC_Interface/fic_ws/install/setup.bash

cd ~/FIC_Interface/fic_api
pip install -e .

Quick Start

from fic_api import Robot

# Connect to simulation (default); also works as a context manager
with Robot(target='simulation', num_joints=7) as r:
    r.set_mode(2)                     # Joint Impedance With Planner
    r.home()
    r.wait_until_stopped()
    q = r.get_current_joints()        # RADIANS, from /robot1_trajectory_data
    print(r.get_joint_positions())    # degrees convenience wrapper

fic_api safety caveats

fic_api bypasses the studio: there is no cooperative Stop button, no GUI E-STOP integration, and stop() only holds the current position. Keep the hardware E-STOP within reach when scripting a real robot, and see Safety. On the Newton GPU backend the simulation force_torque topic publishes empty messages, so get_force_torque() is not meaningful there (see Simulation).

Safety Notes

  • E-STOP: Press Space or the ■ toolbar button at any time. From a script, call robot.safety.estop() or the flat alias stop(). See E-STOP for the graceful torque-ramp behaviour.
  • Degrees: The API uses degrees for joint angles throughout. The conversion to radians (for ROS publishes) is handled internally.
  • Blocking waits: move_joints(wait=True) polls at 20 Hz; a tight Python loop with no cooperative check cannot be interrupted by the Stop button until the current iteration completes. Add if is_stopped(): break inside loops.
  • Sandboxing: Scripts run in the same Python process as the studio. Avoid file system writes to paths outside ~/.fic_studio_scripts/.
