Overview

FIC Control Studio provides a complete pipeline for torque-controlled robotics: a nonlinear impedance control algorithm (FIC), a MuJoCo physics simulator, real hardware drivers, an automated parameter tuner, and a professional PyQt5 interface that ties it all together.

The Studio comprises 9 built-in pages — Dashboard, Multi-Robot, Tuning, Safety, Settings, Robot Config, Topic Monitor, Logs, and this Help viewer — plus the control bar docked to the bottom of every one of them — plus a growing library of optional Extensions that add capabilities such as Auto-Tuning, Sequences, Teach Mode, Script Editor, Teleoperation, Trackers, VR teleop, Experiments, and more. Extensions are enabled individually in Settings → Extensions and each adds its own sidebar entry without modifying the core application. There is also a standalone Python API (fic_api/ at the repo root, pip install -e .) for driving FIC-controlled robots from plain Python scripts or notebooks without the GUI — see Script API for the shared command surface.

Launching

After installation, launch from a sourced workspace:

cd ~/FIC_Interface/fic_ws
source /opt/ros/$ROS_DISTRO/setup.bash
source install/setup.bash

ros2 run fic_studio fic_studio_pro   # FIC Control Studio (full GUI)
ros2 run fic_studio fic_dev          # FIC Dev Console (lightweight hardware GUI)

The one-click installer also registers desktop launcher entries for both apps. The controller (fic_simulation / fic_hardware) runs its loop at 1 kHz; start and stop it from the toolbar or the Processes page.
