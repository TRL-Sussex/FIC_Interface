Tutorials

Step-by-step guides to get you started.

1. First Simulation (5 minutes)

Get a simulated robot moving in under 5 minutes.

  1. Launch FIC Control Studio (Super → search "FIC Control Studio").
  2. Select Franka_FR3 from the Robot dropdown in the toolbar.
  3. In the toolbar set Target to Simulation, then click ▶ Start. A MuJoCo 3D viewer opens with the robot in its home pose and the FIC controller auto-starts about 2 s later. The SIM and FIC status LEDs in the bottom bar turn green. (Equivalent: Simulation → Launch Sim + FIC, F7.)
  4. Open ▲ Joint on the control bar (Simulation target). Drag the joint fields to see the robot respond.
  5. Try different control modes: switch to mode 5 (Cartesian Impedance) and drag the Cartesian target.
  6. Open the Tuning Panel. Drag the stiffness handle on the FIC canvas to see the response change in real time.
Terminal equivalent
source ~/FIC_Interface/fic_ws/install/setup.bash
ros2 launch mujoco_native simulation_launch.py robot_name:=Franka_FR3 &
ros2 launch fic_simulation fic_launch.py robot_name:=Franka_FR3 num_joints:=7 &
ros2 run fic_studio fic_studio_pro

2. Recording a Sequence

Create a repeatable motion sequence.

  1. Start a simulation (SIM + FIC, as above).
  2. Open the Sequences panel.
  3. Click + NEW and name it (e.g. "demo_pick_place").
  4. Pick a Capture Mode from the dropdown — Joint, Cartesian, or Gripper — for the waypoint you're about to add.
  5. Set the values: for a Joint waypoint click READ FROM ROBOT to fill the fields from the current pose (or type angles); for a Gripper waypoint use OPEN / CLOSE.
  6. Set Hold Time (default 1.0 s), then click CAPTURE POSITION to append the waypoint to the table. Repeat for each step.
  7. Tick Loop for continuous repetition, then click ▶ PLAY — the robot moves through each waypoint in turn.
  8. Click SAVE TO YAML to persist; sequences are stored in ~/robot_sequences.yaml and reload with LOAD FROM YAML.

3. Teach Mode

Record waypoints by physically guiding the robot (simulation or hardware).

  1. Start SIM + FIC (simulation) or API + FIC (hardware).
  2. Open the Teach Mode panel.
  3. Click Start Teaching — the robot switches to Joint Admittance (compliant mode).
  4. In simulation, use the control bar's joint fields to "guide" the robot. On hardware, physically move it.
  5. Click ⏺ Record Current Position at each pose you want to save, or enable Auto-record (captures a waypoint every 1 s).
  6. Click Stop Teaching when done.
  7. Review the recorded waypoints in the table on the right; the per-row Go button drives the robot to that waypoint so you can verify it.
  8. Click Save as Sequence to convert to a playable sequence.

4. Auto-Tuning Mode 2

Automatically optimise FIC parameters for smooth joint motion.

  1. Start SIM + FIC with a robot (e.g. Franka_FR3).
  2. Open the Auto-Tuning panel.
  3. Tick Joint Planner (Mode 2) in the phase list.
  4. Review settings: min_score = 85, max_iterations = 12, and the optimiser (Neural Network + CEM — the only algorithm; the legacy PSO / Bayesian / Hybrid labels all map to it). Adjust the PSO particles spinbox to widen or narrow the search.
  5. Click START.
  6. Watch the score improve over iterations. The auto-tuner sends test trajectories and measures the response.
  7. When the score reaches the target (or convergence is detected), tuning stops automatically.
  8. Click Save to write the optimised parameters to config.xml.
  9. Open the Tuning Panel to verify the new parameters visually.

5. Adding a New Robot

Register a new robot model in the system.

  1. Place the robot's URDF in fic_ws/src/menagerie/model/<robot_name>/URDF/<robot_name>.urdf.
  2. Place the MuJoCo model in fic_ws/src/menagerie/model/<robot_name>/xml/<robot_name>.xml, with its scene.xml and assets/ alongside.
  3. Open the Robot Config page in FIC Control Studio (an inline card page since v3.9.3 — the old modal dialog is gone).
  4. Click + ADD, give the robot an ID, then fill in the display name, number of joints, frame names, and the URDF / MuJoCo XML paths (relative to fic_ws/src/). Click Save Robot.
  5. Click DEPLOY TO CONTROLLER to write robots_config.yaml and patch config.xml (this button replaced the old SYNC TO FIC CONFIG).
  6. Rebuild so the new model files are installed: open Settings → click ⟳ Rebuild Workspace (Ctrl+B), or run colcon build --symlink-install in a terminal.
  7. Source the workspace: source install/setup.bash.
  8. Restart the GUI. The new robot appears in the toolbar dropdown.

See the Robot Config page and the menagerie README for detailed model requirements.

6. Writing a Script

Automate robot actions with Python.

  1. Open the Script Editor panel.
  2. Set Target to "Simulation" (or "Hardware").
  3. Click New and write your script: 
    home()
wait(2.0)                                   # home() is non-blocking; let it settle
move_joints([0, 45, -90, 0, 90, 0, 0], wait=True)   # blocks until reached
pos = get_ee_position()
print(f"EE position: {pos}")
home()
  4. Click Run (or Ctrl+R). Output appears in the console.
  5. Click Save to store the script in ~/.fic_studio_scripts/.

See Script API Reference for all available functions.

7. Setting Up Teleoperation

Control a remote robot from a master workstation.

  1. On both machines, launch FIC Control Studio and start a robot session (Simulation or Hardware) so the FIC controller is running on each side. (Teleoperation is a Studio extension — the lightweight Dev Console does not host it.)
  2. Ensure both machines share the same ROS_DOMAIN_ID (Settings → Network) and are on the same DDS-reachable network.
  3. Verify discovery: run ros2 topic list on both machines — each should see the other's topics.
  4. Open the Teleoperation page on each machine and pick a Role from the dropdown — Master on one, Slave on the other. The roles must be opposite; two machines requesting the same role never pair.
  5. Click START TELEOP on both. On pairing, each machine captures its current configuration as "home"; the master then streams its delta from home to the slave.
  6. Move the master robot — the slave applies the scaled, mapped delta to its own home. Force sensed at the slave is reflected back and rendered on the master for bilateral feedback; tune the reflection with the force gain spinbox.
  7. Click STOP TELEOP on either machine to end the session.

See Teleoperation and FIC Dev Console for full details.

8. Using the Dev Console for Hardware

Direct robot control from a workstation next to the robot.

  1. Launch FIC Dev Console on the robot PC.
  2. Select the robot from the toolbar dropdown.
  3. Click ▶ API to start the vendor driver. Wait for the API LED to turn green.
  4. Click ▶ FIC to start the hardware controller.
  5. Select a control mode (e.g. "1: Joint Impedance") and click Send.
  6. Click RESET TO HOME to load the robot's home position into the fields.
  7. Click SEND JOINTS to move the robot to the home position.
  8. Adjust FIC parameters on the Tuning tab as needed.
  9. Use ▶ BAG to record data and ▶ PLT to visualise it.

See FIC Dev Console for the full guide.
