Sequence Programming

Waypoint-based motion sequences with looping, hold-time scaling, and tolerance checking.

Overview

Sequences are ordered lists of waypoints that the robot executes one after another. Each waypoint can be a joint target, Cartesian pose, or gripper command. The sequence player monitors feedback to confirm each waypoint is reached before advancing.

The panel is provided by the sequences extension (Extensions/sequences/extension.py), listed under the Programming sidebar section. Like all optional panels it can be enabled or disabled from Settings → Extensions — see Extensions. Disabling it does not affect the shared joint/EE feedback, which lives in the built-in JointStateMixin.

Creating a Sequence

  1. Open the Sequences panel.
  2. Click + NEW and enter a name, or pick an existing sequence from the dropdown.
  3. Choose the Target (Simulation or Robot 1–4) and the capture Mode:
    • Joint — seven angle spin boxes (degrees, ±360°)
    • Cartesian — X/Y/Z (±2 m) plus axis–angle orientation (unit axis + angle in degrees)
    • Gripper — width 0.0–0.08 m with OPEN / CLOSE preset buttons and a live % readout
  4. Either type values directly, or click READ FROM ROBOT to fill the fields from live feedback ({rid}_q_current for joints, {rid}_ee_current_pose for Cartesian). If no controller feedback has arrived, joint capture falls back to the GUI joint sliders and logs "Read joint positions from sliders (no feedback)". Gripper capture reads the target robot's gripper slider (not available for the Simulation target — set the value manually).
  5. Set Hold Time (0–60 s, seconds to pause at the waypoint after it is reached).
  6. Click CAPTURE POSITION to append the waypoint to the current sequence.
  7. To edit a waypoint: click it in the list (its values load into the capture fields), change values, then click UPDATE. Reorder with the ↑ UP / ↓ DOWN buttons.
  8. Click SAVE TO YAML to persist. Edits live only in memory until you save.
Save explicitly

Captured and edited waypoints are held in memory only. SAVE TO YAML writes all sequences to ~/robot_sequences.yaml; that file is auto-loaded the next time the panel is built. Deleting or renaming a sequence in the panel is also not on disk until you save. The last remaining sequence cannot be deleted.

Execution Flow

  1. Publish the target joint angles (or Cartesian pose, or gripper width) via the appropriate ROS topic.
  2. Monitor position feedback on a 50 ms timer (20 Hz) from {rid}_q_current or {rid}_ee_current_pose.
  3. Check whether the current position is within the configured tolerance. Joint waypoints require every joint within the joint tolerance. Cartesian waypoints also have a settled-near-target fallback (see below). Gripper waypoints have no feedback check — they count as reached 0.3 s after publishing.
  4. Once reached, wait for the hold time (divided by the Speed Scale).
  5. Advance to the next waypoint after a 100 ms gap. After the last waypoint: restart if Loop is checked, otherwise stop with status Sequence Complete.
  6. If the timeout expires before the waypoint is reached, log a warning (Timeout at WP N), skip the hold, and advance.

Settled-near-target advance (Cartesian only)

Cartesian waypoints can advance two ways:

  1. Strict pass — position_error ≤ Pos Tol. Logs ✓ WP N reached (Xs).
  2. Settle pass — position_error ≤ 3× Pos Tol AND the EE has moved less than 1 mm for ≥1.0 s. Logs Cartesian waypoint settled at X.Xmm (beyond Ymm tolerance) — advancing, then the usual reached log line. Catches gravity-loaded poses where the planner has stabilised at its best achievable point but cannot quite hit the strict tolerance.

If a Cartesian waypoint still hits the timeout, the EE never even got within 3× tolerance — that points to a target outside the reachable workspace, the wrong frame, or a singularity, not a tolerance issue. Check the trajectory plot to see where the planner actually went.

Mode-Aware TEACH / PLAYBACK Buttons

The ROBOT MODE (Real Robot Only) group on the left of the panel has two buttons whose behaviour depends on the active capture Mode (Joint / Cartesian / Gripper). Both publish a mode-name string on {rid}_mode_select:

Capture ModeTEACH MODE buttonPLAYBACK MODE button
Joint or GripperPublishes "Joint Admittance" (Mode 3)Publishes "Joint Impedance With Planner" (Mode 2)
CartesianPublishes "Cartesian Admittance" (Mode 7)Publishes "Cartesian Planner" (Mode 6)

This makes recording a Cartesian-space sequence a one-click flow: switch the capture Mode to Cartesian, click TEACH MODE to put the robot in Cartesian Admittance, hand-guide and capture, then click PLAYBACK MODE before pressing Play. See Control Modes for what each mode does. With the Target set to Simulation, both buttons only show an info dialog — the simulator accepts commands directly without a mode switch.

File Format

Sequences are stored in YAML at ~/robot_sequences.yaml:

sequences:
  - name: "pick_and_place_v1"
    waypoints:
      - type: joint
        values: [0.0, 45.0, -90.0, 0.0, 0.0, 0.0, 0.0]
        hold_time: 1.0
      - type: cartesian
        position: [0.5, 0.2, 0.3]
        axis_angle: [0.0, 0.0, 1.0, 0.0]   # ax, ay, az, angle_deg
        hold_time: 0.5
      - type: gripper
        width: 0.0
        hold_time: 0.5
        label: "Close gripper"   # optional; written by Teach Mode, preserved on load

Joint values are stored in degrees and converted to radians at publish time. Unknown keys such as label (added by Teach Mode's Save as Sequence) are preserved through save/load but are not shown or editable in this panel. The file is loaded automatically when the panel is first built, and LOAD FROM YAML re-reads it on demand — replacing all in-memory sequences.

E-STOP behaviour

An emergency stop halts a playing sequence immediately (the extension implements the on_emergency_stop() hook), and Escape stops the sequence player at any time. Stopping the sequence does not cancel a target the controller is already moving toward — the robot finishes converging on the last published waypoint unless you E-STOP. See E-STOP and Safety.

Teach Mode integration

Use Teach Mode to record waypoints by physically guiding the robot. Its Save as Sequence button converts the recording into this panel's schema (joint radians → degrees, quaternions → axis–angle), injects it into the sequence dropdown, and auto-saves ~/robot_sequences.yaml — ready for immediate playback here. Teach Mode requires the Sequences extension to be enabled for this hand-off.
